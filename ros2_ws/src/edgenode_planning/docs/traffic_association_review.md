## 지도 근거와 방향

필드는 없다. MGeo 변환본에는 link/node/global_info만 있어 원본 SHP/DBF를 대조했다.
Type 코드의 의미를 추측하지 않았다. B2 Kind530은 기하 후보이며 공식 의미·실제 정지선

이는 시간상 동시 관측이며 픽셀→지도 객체 동일성의 증명은 아니다.

정규화된 전체 검출 박스 합집합은 [0.53588,0,0.66675,0.03752],

상단 신호가 잘린 원본 영상도 확인했다. 이 값은 **한 정지 위치의 관측 영역**이며

이 영역을 그대로 운용 ROI로 복사하지 않는다.

## 저속 시험 전과 시험 절차

1. 지금은 기능 비활성을 유지한다. 운전자가 정지 상태에서 정지선·대상 신호·차로·회전 허가를
   MORAI 화면과 지도 ID로 확인한다. 다른 차로와 반대 신호도 함께 라벨링한다.
2. 실제 전면 오프셋·정지 여유·제동/지연을 확인한다. 현재처럼 기준점이 선0.9m 전이면
   전면은 이미 지났을 수 있으므로 충분히 뒤쪽 안전 위치에서 준비한다.
3. 운전자가 직접 수동 접근/재배치하며 여러 거리에서 원본 영상·신호ID·pose를 구독 기록한다.
   픽셀 대상·왜곡/외부보정·ROI 전체 접근 구간 및 UNKNOWN/오인식을 검증한다.
4. 우회전/화살표 허가를 색상모델로 추정하지 않는다. 우선 검증 가능한 직진 구간을 선택한다.
5. 검증 근거가 확보된 항목만 별도 association에 등록하고 정확한 route hash와
   실측 stop_policy를 기록한다. 재경로/Reset 후 hash·방향·위치가 바뀌면 재검증한다.
6. 운영자가 계획한 코드 적용 후에도 주행 해제 상태에서 거리·상태를 확인한다.
   감독자가 즉시 MORAI 일시정지 가능한 상태에서, 사용자가 직접 1km/h 이하 시험을 활성화한다.
7. 빨강 정지·브레이크 유지·짧은 초록 거부·연속 초록 출발·영상 중단/다른 차로 신호를 점검한다.
   이상 시 주행 해제, 정지 미확인 시 수동 일시정지한다. 고속 적용은 별도 검증 전 금지한다.
